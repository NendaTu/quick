# config.py Variable Trace Document - 2026-07-08

## Summary of Issues
- **Defined but Unused/Orphaned**: `RELAXED_ROE_TARGET` is defined in `config.py` but never used in any logic (even `models.py` uses a hardcoded 0.20 or strategy-specific targets).
- **Missing (should exist but doesn't)**: `SL_MOVE`, `TP_MOVE`, and `TARGET_NET_ROE` are referenced in `models.py` with `getattr` defaults but are not present in `config.py`.
- **Partially Connected**: `REENTRY_COOLDOWN` is implemented as a global 60s hardcode in `Engine`, which may be too rigid for high-frequency strategies.
- **Redundant Logic**: `MIN_CONFIDENCE` has a default of 0.66 in `config.py` but is also hardcoded as 0.66 in `models.py`'s `getattr` default.
