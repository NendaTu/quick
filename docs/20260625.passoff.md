# Project Pass-Off: Hardened High-Frequency Compounding System
**Date**: 2026-06-25
**Current Status**: Infrastructure stabilized; Risk management hardened; Ready for Phase 3 (Learning & Scaling).

## 1. Architectural Transformation
Since the baseline pass-off (2026-06-24), the system has evolved from a static prototype into a dynamic, production-ready environment.

### Core Upgrades:
- **Dynamic Asset Discovery**: The bot no longer relies on a hardcoded list. It discovers the top 100 assets by volume via the BitGet API during warm-up.
- **Multi-Timeframe (MTF) Engine**: Support for simultaneous analysis of 1m, 5m, and 15m intervals. DRT (Directional Trend) is now calculated across these timeframes to provide macro-momentum awareness.
- **Contrarian Mode**: Implemented `CONTRARIAN_GLOBAL` and `CONTRARIAN_FILTER` toggles to allow for inverted signal experiments while preserving SL/TP ratios.
- **Rate-Limit Resilience**: Integrated exponential backoff and random jitter into `BitGetClient` to handle HTTP 429 errors during 100-asset warmup.

## 2. Advanced Risk & Execution Models
The "Bleed" on losses has been identified as the primary hurdle to compounding. Four new mechanisms were implemented to protect capital:

- **Soft-Stop (Maker-Exit)**: The bot now places a **Limit SL** by default. If the price moves past a `SL_DISASTER_BUFFER` (0.1%), it fires a Market backup. This captures Maker fees on most exits and eliminates slippage.
- **Breakeven Trigger**: Once a trade hits `+2.5% ROE`, the SL is moved to the **Entry Price + Buffer**, ensuring a "Free Ride" to the TP target.
- **TTL (Time-to-Live) Exit**: Stagnant trades are now forcefully exited via Mid-price Limit order after `TRADE_TTL_SECONDS` (180s) to avoid being trapped in trend reversals.
- **Adaptive RSI**: Entry windows now tighten to 25/75 in low-momentum zones and relax to 40/60 only when high-timeframe momentum is confirmed.
