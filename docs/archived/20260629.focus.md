# Session Document - 2026-06-29: Backtest.py Implementation

## Overview
Implementation of a new `backtest.py` entry point for the Bitget USDT-M Futures trading system. This tool allows backtesting individual technical analysis conditions against historical data.

## Requirements & Design Decisions
1. **Isolated Condition Testing**: Backtesting utilizes conditions outlined in the file called from `ta/`, and relevant global conditions from `config.py`. It treats the called condition as the exclusive entry signal.
2. **Exit Logic**: Standard exit strategy from `config.py` (e.g., `BE+TP1+TP2`) is used, with overrides available via `backtest.py`.
3. **Condition Interface**: Adopted "Option A" (Template approach). Every strategy file in `ta/` implements `get_signal(ohlcv, timeframe) -> Optional[Dict]`.
4. **Win% (TP) Definition**: Defined as any trade with a net profit (after slippage and round-trip fees).
5. **Date Range & Asset Scope**: Default range is June 1, 2022, to June 1, 2026. Default assets: ETH, HBAR, UNI, GRT. Supports 1m, 3m, 5m, 15m timeframes.
6. **Data Granularity**: Candle-level simulation is sufficient.
7. **Recursive Search**: `python backtest.py [query]` searches `ta/` recursively. Supports singular-to-plural mapping (e.g., `candle/` -> `candles/`).

## Implementation Details
- **`tools/trading_utils.py`**: Created to house shared math for fees, PnL, and ROE targets.
- **`ta/strategy_interface.py`**: Defined the standard interface for strategies.
- **`ta/candles/engulfing.py`**: Implements body-only engulfing.
- **`ta/candles/engulfing_total.py`**: Implements wick-to-wick engulfing.
- **`backtest.py`**:
    - Historical data downloader with progress bar.
    - Candle-by-candle simulation loop.
    - Multi-asset/multi-timeframe results table.
- **`database.py`**: Extended with range-query and stats-query functions for efficient backtesting.

## ROE/ROI Calculation
Net ROE is calculated after accounting for:
- Maker/Taker fees (0.02% / 0.06% default).
- Expected Slippage (0.1% per leg for taker orders).
- Leverage (20x assumed for target calculation).

The `calculate_tp_for_roe` utility solves the algebraic equation to find the exact exit price needed to net a specific ROE after all costs.
