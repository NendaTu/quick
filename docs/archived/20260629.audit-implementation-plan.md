# Audit Implementation Plan - June 29, 2026 [COMPLETED]

This document translates the findings from the June 29 audit into a series of actionable engineering tasks to harden the Bitget Trading Bot.

## Phase 1: Core Architecture & Reliability

### 1.1 Optimize Feature Calculation Loop [CS-001]
- **Action:** Introduce a cache-aware feature calculation in `simulator.py`.
- **Status:** COMPLETED. Implementation in `get_features` now strictly validates cache timestamps and separates tick-based metrics from candle-based patterns.

### 1.2 Centralize Position State [CS-002]
- **Action:** Refactor `Engine` to treat the exchange/simulator as the master of truth for position data.
- **Status:** COMPLETED. Pre-emptive local state population removed from `engine.py`. Fill callbacks are now the primary trigger for state updates.

### 1.3 Configuration Hardening [CS-003]
- **Action:** Move pattern-specific configuration to their respective files and implement a validator.
- **Status:** COMPLETED. Settings for RSI, ATR, DRT, FVG, OB, Liquidity, and Structure moved into their respective modules. `config.py` refactored to focus on environment and global risk.

### 1.4 Comparison Suite Equity Sync [CS-004]
- **Action:** Ensure all variant runners use the same starting equity baseline.
- **Status:** COMPLETED. `DataCoordinator` now pre-captures `INITIAL_EQUITY` and propagates it to all `VariantRunner` subprocesses.

### 1.5 LearningModel Clean-up [CS-005]
- **Action:** Gate learning logic to save CPU.
- **Status:** COMPLETED. `USE_ONLINE_LEARNING` toggle added to `config.py` and enforced in `models.py`.

## Phase 2: Technical Analysis Hardening

### 2.1 Standardize Indicator Smoothing [TA-001]
- **Action:** Replace simple averages with recursive smoothing.
- **Status:** COMPLETED. Wilder's Smoothing implemented in `ta/indicators/rsi.py` and `ta/indicators/atr.py`.

### 2.2 Eliminate Look-Ahead Bias [TA-002]
- **Action:** Enforce "Closed Candle Only" rule for structural patterns.
- **Status:** COMPLETED. FVG, Market Structure, and Order Block detection now anchor to `ohlcv[:-1]`.

### 2.3 DRT Stability [TA-003]
- **Action:** Anchor DRT to fixed intervals.
- **Status:** COMPLETED. `compute_drt` refactored to use modular periods and stable price series.

### 2.4 POI Weighting [TA-004]
- **Action:** Upgrade the POI scoring system.
- **Status:** COMPLETED. Weighted scoring implemented in `ta/patterns/poi.py` (OB=50, Liquidity=40, FVG=30).

### 2.5 Session Continuity [TA-005]
- **Action:** Ensure session extremes persist across restarts.
- **Status:** COMPLETED. `Simulator.warm_up` modified to fetch 1000 candles (max Bitget limit) to capture trailing session data.
